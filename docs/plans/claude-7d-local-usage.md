# Claude 7d 本站累计用量补齐计划

## 目标与范围

参考 Codex，为 Claude OAuth / Setup Token 账号展示本站已落库日志的 7d 请求数、token 和费用。新增统计只读数据库及已有被动采样，不新增上游请求或定时探测。保留手动主动查询和现有响应头采样入口；只补所有模型合计的 7d，不扩展 7d S / 7d F，不推算官方 token 配额。按用户后续要求，通过功能 PR 合入 fork，保持线性补丁栈和 upstream-release 锚点，不额外触发发布或执行部署。

## 后端与统计口径

复用 GetAccountWindowStats 和 WindowStats。重置时间可解析、未过期且距当前不超过 7 天时，从 resets_at − 7 天统计当前周期；其他情况统计最近 7 天。自动加载使用 GetPassiveUsage 的已有采样，手动查询使用原响应的周期信息。token 为输入、输出、缓存写入、缓存读取之和；费用沿用现有口径。

结果写入 seven_day.window_stats；没有官方采样仍返回本地统计，并标记官方额度未知。主动查询缺失的官方字段回写 null，避免旧使用率或旧重置时间残留；仍有效的周期边界独立保留供本地统计使用。5h / 7d 独立处理查询失败，不把失败显示或缓存成零。缓存 TTL 为 1 分钟，每账号分别保存两个窗口和周期身份；周期或模式变化立即失效，最近 7 天模式在 TTL 内复用。

## 接口与展示

无需迁移或新 API。UsageProgress 增加可选 window_stats_period（cycle / last_7_days）、quota_available。其他平台省略字段保持原行为；Claude 缺少官方使用率或重置时间过期时标记额度未知。

Claude 7d 行复用现有统计组件，增加本站记录范围及当前周期 / 最近 7 天的国际化提示。额度未知时隐藏官方百分比、进度条和倒计时，显示官方额度未知；本地统计独立显示。零用量沿用现有展示。自动加载 / 刷新继续 source=passive，手动主动查询保留，Codex 不变。Claude 被动读取（包括 fork 的桌面批量加载路径）绕过原有 5 分钟前端缓存，使用后端 1 分钟统计缓存。

## 验证与验收

后端覆盖周期计算及回退、OAuth / Setup Token、缺失和零使用率、缓存隔离及失效、查询失败隔离 / 重试、被动路径零上游请求。固定时间及日志样本验证起点前记录排除、起点及之后记录计入、缓存 TTL。

前端覆盖统计传递、区间提示、额度未知展示、被动加载 / 刷新及手动查询保留，回归 5h / 7d S / 7d F / Codex。运行相关 Go 测试、组件测试、类型检查及可用的浏览器验证。

## 数据边界

仅统计本站仍保留的已落库记录，绕过本站、未落库及已清理请求不能补算；最近 7 天不宣称为官方当前周期。
